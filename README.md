# Codewave-Hackathon-Himalayan-JavaScript
Margaa is a digital solution to two of the biggest problems of Nepali Public Transport, namely: lack of access to different points and overcrowd of vehicles in certain parts of the road. Margaa, our open source project by Team Himalayan Javascript, uses Javascript (not a shocker) and existing open source projects like OpenStreetMap and other projects.
There are two solutions. First, like ride sharing apps from which the UI is based off of, we enter our starting point and destination. Now, using Djikstra's algorithm, existing bus routes and posted fares, we show the most optimal path to get to the destination using only public transportation. If certain path from starting point or destination is unreachable by bus, we can also show the path they need to walk or use actual ride sharing app if the path is too long.
Second, we optimize the traffic. Like airports and railways, buses will use time alloted token system, and can only leave the bus park when thier token is up. With coordination with other public transportation organizations and bus parks, this makes the roads less conjested and more safe. Also, mobile app version will use gps from driver's phone to know the exact location of the bus so that people can know when the bus they want, suggested by Margaa, is going to arrive.
